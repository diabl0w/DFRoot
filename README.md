# PixelRoot

Monochrome OLED root launcher, execution log viewer, and standalone `/data/adb/ksud` module manager for Android.

## Features
- **Pure OLED Monochrome UI:** High-contrast `#000000` black and white theme with custom rounded-crosshair iconography.
- **3-Tab Carousel Navigation:** Smooth horizontal swipe and bottom-pill navigation across **Launcher**, **Root Log**, and **Modules**.
- **Standalone Module Control:** View `/data/adb/modules`, toggle module states, and install module `.zip` packages directly via `/data/adb/ksud`.
